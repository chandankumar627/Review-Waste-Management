║                              DATA FLOW                                        ║
╚═══════════════════════════════════════════════════════════════════════════════╝

UPLOAD FLOW:
───────────
1. User selects image in React UI
2. Frontend sends FormData to Backend (POST /api/uploadWaste)
3. Multer saves image to /uploads folder
4. Backend converts image to base64
5. Backend sends to AI Service (POST /predict)
6. AI Service returns { category, confidence }
7. Backend saves to MongoDB (WasteLog collection)
8. Backend returns result to Frontend
9. Frontend displays result with confidence bar

DASHBOARD FLOW:
──────────────
1. User opens Dashboard page
2. Frontend requests stats (GET /api/stats)
3. Backend queries MongoDB:
   - Count today's predictions
   - Aggregate category statistics
   - Get latest prediction
4. Backend returns aggregated data
5. Frontend renders:
   - Stats cards
   - Pie chart (Recharts)
   - Recent history list
