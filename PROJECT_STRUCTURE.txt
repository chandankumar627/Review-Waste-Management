ARCHITECTURE FLOW:
==================
1. User uploads image → React Frontend
2. Frontend sends to → Node.js Backend (POST /api/uploadWaste)
3. Backend saves image → uploads/ folder
4. Backend forwards to → Python AI Service (POST /predict)
5. AI Service returns → { category, confidence }
6. Backend saves to → MongoDB
7. Backend returns result → Frontend
8. Frontend displays → Result + Updates Dashboard
